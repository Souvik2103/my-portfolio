## 📌 Overview
This is my personal portfolio website designed to showcase my journey as a **Data Analytics & Fintech Enthusiast** and a final-year student at **IIT (ISM) Dhanbad**. 

The site serves as a central hub for my technical projects, resume, and professional profiles, featuring a modern, responsive "Dark Mode" aesthetic with glassmorphism effects.

🔗 **Live Demo:** [https://souvik2103.github.io/my-portfolio/##projects]

---

## 🚀 Features
* **Responsive Design:** Fully adaptive layout that works seamlessly on desktops, tablets, and mobile devices.
* **Modern UI/UX:** Built with a custom dark gradient theme (`#0f172a` to `#312e81`) and neon accents.
* **Interactive Cards:** Project cards with hover animations and direct links to source code/dashboards.
* **Glassmorphism:** CSS backdrop-filters used for a sleek, frosted-glass look.
* **Clean Code:** Written in semantic HTML5 and vanilla CSS3 (no heavy frameworks).

---

## 🛠️ Tech Stack
This portfolio is built using:
* **HTML5:** Structural markup.
* **CSS3:** Custom variables, Flexbox, CSS Grid, and Keyframe animations.
* **FontAwesome 6:** For social media and UI icons.
* **Google Fonts:** Using 'Segoe UI' and sans-serif stacks for typography.

## 💻 How to Run Locally

1.  **Clone the repository**
    ```bash
    git clone [https://github.com/Souvik2103/Portfolio.git](https://github.com/Souvik2103/Portfolio.git)
    ```
2.  **Navigate to the project directory**
    ```bash
    cd Portfolio
    ```
3.  **Open the file**
    Simply double-click `index.html` to open it in your default web browser.
